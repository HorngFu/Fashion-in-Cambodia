This directory is built by volunteers. Every shop you add helps someone find what they need.

## Suggest a shop

Know a shop that sells fabrics, clothing, tools or fashion services? [Suggest a shop on GitHub](https://github.com/HorngFu/Fashion-in-Cambodia/issues/new?template=new-shop.yml). An editor checks the details and adds it.

## Report wrong information

Shop closed or moved? Phone number changed? Every shop page has a **Report wrong information** link.

## Become a volunteer editor

Editors add and check shops with a simple web editor. [Tell us you want to help](https://github.com/HorngFu/Fashion-in-Cambodia/issues/new) and which area of Cambodia you know.

## Translate or write code

The site is in Khmer and English, and the code is open source. Read the [contributing guide](https://github.com/HorngFu/Fashion-in-Cambodia/blob/main/CONTRIBUTING.md) to get started.
